# Smile Clinic design

기존 스마일 로고를 유지하고 [원안과](https://www.oneretinaclinic.com/)의 레이아웃과 인터랙션을 참고해 새로 구현한 정적 홈페이지입니다. 원본 사이트의 코드, 사진, 문구를 복제하지 않았습니다.

## 실행

- `npm run dev` — http://127.0.0.1:8080
- `npm run build` — 정적 배포용 `dist/` 생성 및 로컬 자산·앵커·JavaScript 구문 검사
- 또는 XAMPP Apache를 실행하고 http://localhost/smile/ 접속

외부 JavaScript 라이브러리나 설치할 패키지는 없습니다. 글꼴은 DM Sans와 Noto Sans KR로 통일하며 Google Fonts를 사용합니다. 외부 연결이 없어도 시스템 글꼴로 표시됩니다.

## 구현 범위

- 반응형 헤더 및 키보드 지원 전체 메뉴: 헤더 아래로 슬라이드다운하며 열리고 위로 접히며 닫힙니다. 연속 클릭 시 현재 높이부터 반대로 진행하고, 동작 줄이기 설정에서는 즉시 전환합니다.
- 자동 재생/일시 정지/좌우 이동/터치 스와이프 메인 슬라이드
- 스크롤에 따른 소개 문구 채움, 요소 등장, 2단 진료 철학 전환
- 중앙 확대 진료 카드 슬라이더(마우스 드래그, 터치, 키보드, 점·화살표 탐색)
- 영문 무한 마키, 공간 슬라이드, 소식 호버 미리보기
- 진료 카드 선택, 소식 미리보기, 빠른 메뉴 및 맨 위로 이동 (모달 없음)
- 모바일 세로 레이아웃 및 동작 줄이기 설정 대응

`index.html`에서 콘텐츠, `assets/css/style.css`에서 디자인, `assets/js/main.js`에서 인터랙션을 수정합니다.

사진 2장은 디자인용으로 새로 생성한 이미지이며 실제 병원을 촬영한 사진이 아닙니다. 소식과 운영 시간도 예시입니다. 실제 예약·문의 전송 기능은 포함하지 않습니다.

## 스크롤 연출

`assets/js/scroll-effects.js`와 `assets/css/scroll-effects.css`에서 네 섹션의 연출을 관리합니다.

- about: 데스크톱 300svh 구간에서 심볼 등장 → 왼쪽 이동 → 두 문단 순차 등장. 모바일은 고정 없이 순차 등장합니다.
- clinic: 정사각형 비율의 의료 십자(+) 윤곽을 스크롤에 맞춰 그립니다. 데스크톱은 중앙의 큰 심볼을 그리며 역스크롤 시 되돌아가고, 모바일은 각 진료 블록의 심볼을 완성한 뒤 유지합니다. SVG 비율을 고정해 화면 폭에 따라 형태가 늘어나지 않습니다.
- values: 데스크톱 250svh 구간에서 왼쪽 내용을 위아래로 닫고 오른쪽 내용을 중앙에서 확장합니다. 1024px 이하는 세로 배치입니다.
- vision: PC·모바일 모두 200svh 고정 구간에서 문장 등장 후 글자별 색상을 채웁니다.

동작 줄이기 설정에서는 고정과 애니메이션을 해제하고 모든 내용을 바로 표시합니다.

## 푸터와 지도 연결

`assets/css/footer.css`에서 첨부 레퍼런스 기반의 푸터를 관리합니다. 지도는 `index.html`의 `#clinic-map` 빈 컬러 박스에 연결하면 됩니다. 주소·연락처·사업자 정보는 푸터에서 교체할 수 있습니다.

푸터 상단은 지도와 오시는 길·상담·진료시간을 좌우로 배치하고, 하단은 어두운 배경에 로고와 사업자 정보를 중앙 정렬합니다. 네이버·카카오 길찾기 버튼 2개와 정책 버튼은 연결 전까지 비활성 상태로 유지합니다. 주소 및 정책 페이지 확정 시 링크로 교체합니다. 버튼 클릭 시 모달을 여는 기능과 모달 마크업은 모두 제거했습니다.
