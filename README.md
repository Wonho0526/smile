## 리줌 서브페이지 · 아임웹

- `imweb-rezum.html` — 아임웹 코드 위젯에 내용 전체를 붙여 넣는 원본 파일입니다. CSS와 JavaScript가 포함되어 있으며, 스타일과 동작은 `#smile-rezum-widget` 내부에 한정됩니다. 한 페이지에 한 번 삽입합니다.
- `rezum.html` — 브라우저 확인용 리줌 페이지입니다. 이제 아임웹 파일과 별도로 관리하며, `content/subpages.json`에서 내용을 수정합니다.
- 개발 서버에서는 `/rezum.html`, XAMPP에서는 `/smile/rezum.html`로 열 수 있습니다.

메인페이지와 같은 폰트 스택과 민트·딥그린 색상을 사용하며, 헤더와 푸터는 제외한 본문 전용 파일입니다. 섹션 이동과 현재 위치 표시, 스크롤 등장 및 카드 호버 효과를 포함합니다. 모달과 추가 외부 라이브러리는 없습니다. 폰트는 기존 사이트에 로드된 글꼴 또는 시스템 대체 글꼴을 사용합니다.

장비·시술 사진은 컬러박스로 두었습니다. 사진을 연결할 때 해당 `<img>`의 `src`를 바꾸고 `alt`를 실제 이미지 설명으로 수정하세요.

아임웹용 파일의 메인페이지 링크는 `/`로 지정되어 있습니다. 메인페이지 경로가 다르면 `data-sr-home`이 붙은 링크의 `href`를 바꿉니다. 서브페이지는 새 코드 위젯에 삽입하며, 기존 메인페이지 파일은 유지됩니다.

치료 원리와 회복 안내는 [제조사 치료 원리](https://www.rezum.com/what-is-rezum/how-does-it-work.html)와 [제조사 FAQ](https://www.rezum.com/what-is-rezum/faq.html)를 참고했습니다. 특정 환자의 적응증이나 치료 효과를 보장하는 표현은 사용하지 않았습니다.
## 기존 홈페이지 기반 서브페이지 · 브라우저 전용

- `subpages.html` — 전체 35개 페이지를 진료 분야별로 열어보는 목록입니다. 파일을 브라우저로 직접 열거나, 개발 서버의 `/subpages.html`로 접속합니다.
- `rezum.html` — 리줌 페이지의 기존 주소를 유지합니다.
- `subpages/*.html` — 병원 소개, 의료진, 장비, 오시는 길, 전립선, 요로결석, 남성·여성 진료, 성병·검진 및 건강 정보 페이지입니다.
- `content/subpage-manifest.json` — 기존 홈페이지 메뉴와 페이지 주소의 대응표입니다.
- `content/subpages.json` — 각 페이지 본문, 섹션 구성, 원본 출처를 관리합니다.
- `assets/css/subpages.css`, `assets/js/subpages.js` — 브라우저 페이지에만 적용되는 공통 디자인과 섹션 이동·등장 효과입니다.
- `scripts/build-subpages.mjs` — 위 콘텐츠로 브라우저 HTML을 생성합니다. `npm run build`에 포함되어 있습니다.

[기존 스마일비뇨의학과 홈페이지](https://smileuro.com/)의 공개 메뉴와 이미지 안의 본문을 확인해 내용을 재구성했습니다. 중복된 리줌·전립선 질환 주소는 하나의 페이지로 합쳤고, 로그인 전용 주소와 공통 정책 모달은 제외했습니다. 각 페이지의 출처와 원문에 있던 오류·보장 문구의 편집 내역은 콘텐츠 데이터의 `source`, `sourceImages`, `sourceNotes`에 기록합니다.

모든 서브페이지에는 공통 헤더·푸터가 없으며, 모달이나 예약 폼도 포함하지 않습니다. 이미지는 민트 계열 컬러박스이고, 오시는 길의 지도도 연결 전 빈 컬러박스로 유지합니다. 본문은 HTML에 들어 있어 파일로 직접 열어도 내용을 볼 수 있습니다. Google Fonts는 메인과 동일하며, 외부 연결이 없으면 같은 시스템 글꼴 스택으로 표시합니다.

건강 정보 페이지는 기존 게시판의 공개 글 17개 제목과 원문 링크를 제공합니다. 개별 게시글 상세 본문은 기존 홈페이지에서 열립니다.

브라우저 전용 파일을 생성해도 `imweb-rezum.html`, `imweb-widget.html`, `index-combined.html`은 변경되지 않습니다. 아임웹 파일에 이 변경을 자동으로 반영하지 않습니다.
